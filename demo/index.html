tag-sphere

Lightweight 3D rotating tag sphere. Works with Vanilla JS, React and Astro. No runtime dependencies.

npm install tag-sphere GitHub →

Three theming variants

All driven by CSS custom properties — no configuration needed.

Dark
#tc { --ts-bg: rgba(255,255,255,0.05); --ts-color: #c8c8e8; }
Light
#tc { --ts-bg: #fff; --ts-color: #1e293b; }
Glassmorphism
#tc { --ts-blur: blur(8px); --ts-bg: rgba(255,255,255,0.06); }

Usage

Drop-in for any framework

One function, three environments, zero dependencies.

Vanilla JS 
import { tagSphere } from 'tag-sphere';

const instance = tagSphere(
  document.getElementById('tc'),
  { tags: ['Astro', 'TypeScript'],
    radius: 120, speed: 0.03 }
);

// later:
instance.destroy();
React 18+ 
import { TagSphere } from 'tag-sphere/react';

<TagSphere
  tags={['Astro', 'TypeScript']}
  radius={120}
  speed={0.03}
  style={{ width: 300, height: 300 }}
/>
Astro 
import TagSphere from 'tag-sphere/astro';

<TagSphere
  tags={['Astro', 'TypeScript']}
  radius={120}
  speed={0.03}
  client:visible
/>
