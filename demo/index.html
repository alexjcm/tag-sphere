tag-sphere

Lightweight 3D rotating tag sphere. Works with Vanilla JS, React and Astro. No runtime dependencies.

Usage

Vanilla JS 
import { tagSphere } from 'tag-sphere';

const instance = tagSphere(
  document.getElementById('tc'),
  { tags: ['Astro', 'TypeScript'],
    radius: 120, speed: 0.03 }
);

// later:
instance.destroy();
